# Book Vibe — Book Listing Application

A book listing application built with **Next.js** as a hands-on learning project to practice essential Next.js concepts through a complete application.

The interface is designed with the help of **DaisyUI and Claude** to create a clean, modern, and user-friendly experience, while my primary focus is on data fetching, routing, rendering, and application logic.

## Live Demo

**Live Website:** https://book-vibe-library-rho.vercel.app/

**GitHub Repository:** https://github.com/Md-Adnan-Talukdar/Book-Vibe-Library

## Key Features

- **Book Listing:** Browse and explore a collection of books.
- **Book Details:** View detailed information about individual books.
- **Wishlist:** Save books for future reading.
- **Read List:** Keep track of books in your reading list.
- **Listed Books:** Manage Read List and Wishlist using separate tabs.
- **Dynamic Routing:** Navigate to individual book detail pages.
- **Data Fetching:** Fetch and dynamically render book data.
- **Shared State Management:** Share book-list data across components using React Context API.

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Md-Adnan-Talukdar/Book-Vibe-Library.git
```

### 2. Navigate to the Project Directory

```bash
cd Book-Vibe-Library
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## Project Purpose

Book Vibe is part of my journey toward mastering Next.js through practical implementation. The main goal of this project is to understand how routing, data fetching, rendering, and state management work together to build an interactive web application.

I used DaisyUI and Claude-assisted design ideas to improve the visual presentation while keeping my primary focus on the underlying functionality and Next.js concepts.
